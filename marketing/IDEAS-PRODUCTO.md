# Ideas de producto para promocionar

Solo propuestas. **No implementar sin confirmación del usuario.**

| Idea | Por qué ayuda |
|---|---|
| Importar/exportar perfiles (`.nexodeck-profile`) y galería comunitaria | La gente comparte setups de OBS, Premiere, DaVinci, Discord, VS Code y juegos; cada perfil compartido trae usuarios nuevos. |
| Perfiles de ejemplo al instalar (Programación, Edición, Streaming, Juegos) | El primer minuto ya se ve útil, sin configurar nada. |
| Encender la PC desde el celu (Wake-on-LAN) | **Ya implementado en 0.3.0**: permite abrir la app y prender la PC apagada; es un gancho fuerte para el video. |
| Modo "Dock" (celular por USB como panel fijo con atenuación OLED) | Convierte un celular viejo en hardware dedicado; historia ideal para TikTok. |
| Botón "Compartir mi setup" que genera una imagen de la botonera | Cada usuario produce material listo para redes sin esfuerzo. |
| Enlace "Ayudame a traducir" y más idiomas | Amplía el alcance y da una tarea de entrada clara para contribuir. |
