# Plantillas de respuesta

Responder corto, sin vender de más.

**¿Es gratis?**
> Sí, gratis y open source. No hay versión paga ni funciones bloqueadas. El código está en GitHub.

**¿Hay para iPhone?**
> Sí, pero desde Safari como PWA: no hay app nativa ni USB en iPhone. La guía está en el link.

**¿Funciona en Mac/Linux?**
> No por ahora. El servidor es para Windows 10/11; el cliente es web, pero el proyecto no soporta otro sistema.

**¿Es seguro? / ¿Manda datos a algún lado?**
> Todo queda en tu red local: no hay cuentas, nube ni telemetría. El código es abierto para revisarlo.

**¿Link?**
> En la bio 👆 o buscá el repo en GitHub (NexoDeck).

**¿Qué celular necesito?**
> Cualquier Android o iPhone con navegador. Para la app Android, Android 8 o superior.

**¿Se puede usar con la PC apagada?**
> Con la versión 0.3 se puede encender por Wake-on-LAN si la placa y el adaptador lo tienen activado. Todavía no está publicada.

**¿Cómo lo instalo?**
> Descargás el instalador, lo abrís en la PC y escaneás el QR con el celular. Tres pasos, sin cuentas.

**¿Por qué Windows me avisa que es peligroso?**
> Porque el instalador no tiene firma comercial. Podés verificar el SHA-256 del release y seguir con "Más información → Ejecutar de todas formas".
