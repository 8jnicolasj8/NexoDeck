OpenDeckLOCAL CONTROL
EMPAREJAMIENTO SEGURO

Un paso de seguridad y listo.

Para que tu celular se conecte en forma segura, instalá una vez el certificado local de OpenDeck.

1
Descargá el certificado

Se usa únicamente para reconocer a tu PC en la red local.

2
Instalalo en Android

Ajustes → Seguridad → Cifrado y credenciales → Instalar un certificado → Certificado de CA.

3
Continuá a OpenDeck

El código se canjea una sola vez y vence en cinco minutos.

Descargar certificado

La conexión permanece dentro de la red local. El certificado no comparte datos con ningún servicio externo.
